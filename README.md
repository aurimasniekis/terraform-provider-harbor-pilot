# Terraform Provider for Harbor Pilot

Manages [Harbor Pilot](https://github.com/aurimasniekis/go-harbor-pilot) configuration through its control-plane API. Harbor Pilot is a self-hosted LLM gateway and policy control plane. The provider covers:
- providers and accounts (with secret references);
- pools, model aliases, and routing plans with versioned publication;
- client bindings and gateway credentials;
- quota monitors and budgets;
- privacy and trace policies;
- event destinations, notification channels and rules;
- service principals, API tokens, authentication settings and SSO providers.

The provider is not published to the Terraform Registry yet. Build it locally and use `dev_overrides`, as described in [Development](#development).

## Quick start
```hcl
terraform {
  required_providers {
    harborpilot = { source = "aurimasniekis/harbor-pilot" }
  }
}

provider "harborpilot" {} # HP_SERVER, HP_API_TOKEN_FILE

resource "harborpilot_workspace" "eng" {
  name = "engineering"
  spec = jsonencode({ display_name = "Engineering" })
}
```

## Documentation
- [`docs/`](docs/index.md) has the provider and resource reference. It is generated by `make docs`.
- [`examples/scenarios`](examples/scenarios) has seven complete configurations:
  1. Personal Claude Code setup.
  2. Several harnesses sharing subscription pools.
  3. Project budgets with API fallback.
  4. Privacy with 3-day traces.
  5. Availability-first passthrough.
  6. Pulse events and notification routing.
  7. SpaceMan integration.

  The acceptance tests apply each one to a real server.
- [`docs/DECISIONS.md`](docs/DECISIONS.md) explains the design: specs, convergence, secrets, plan versions and testing.

## Requirements
- Terraform 1.0 or later. Write-only secrets need 1.11, and the ephemeral token needs 1.10.
- Go 1.27 to build.
- A Harbor Pilot server, plus a service principal API token with the permissions for the resources you manage.

## Development
```shell
make build       # provider binary in ./bin
make test        # unit tests
make testacc     # acceptance tests (builds and runs harbor-pilot from ../go-harbor-pilot)
make docs        # regenerate docs/ with tfplugindocs
make lint
```

Acceptance tests honor these variables:
- `HP_APP_DIR`: path to the application checkout.
- `HP_APP_BIN`: a prebuilt server binary.
- `TF_ACC_TERRAFORM_PATH`: a specific Terraform binary. Without it, the latest Terraform 1.x is downloaded.

To use a local build from Terraform:
```hcl
# ~/.terraformrc
provider_installation {
  dev_overrides {
    "aurimasniekis/harbor-pilot" = "/path/to/terraform-provider-harbor-pilot/bin"
  }
  direct {}
}
```
